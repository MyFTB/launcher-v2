# Launcher Feedback - Post Guidelines

Willkommen im Launcher Feedback Forum! Damit wir euch schnell und gezielt helfen können, beachtet bitte folgende Richtlinien.

## Tags

Bitte wählt beim Erstellen eines Posts den passenden Tag:

- **Frage** - Ihr habt eine Frage zur Bedienung oder zu einem Feature des Launchers
- **Bug** - Ihr habt einen Fehler gefunden oder etwas funktioniert nicht wie erwartet
- **Verbesserung** - Ihr habt eine Idee oder einen Vorschlag für ein neues Feature oder eine Verbesserung

## Bug melden

- Beschreibt kurz was passiert ist und was ihr erwartet hättet
- Welches Betriebssystem nutzt ihr? (Windows / macOS / Linux)
- Welches Modpack ist betroffen?
- Hängt wenn möglich die Log-Datei an (Einstellungen -> "Log-Ordner öffnen")

## Verbesserung vorschlagen

- Beschreibt eure Idee so konkret wie möglich
- Was genau würdet ihr euch wünschen und warum?

## Allgemein

- Schaut vorher ob euer Thema bereits existiert
- Ein Thema pro Post
- Bleibt beim Thema
